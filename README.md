# GTA III / Vice City Ambulance Full Warning Mod

This mod makes the "Ambulance full" notification appear on-screen as soon as the ambulance becomes full during paramedic missions.

# Installation

**III**:

1. Install the Ultimate Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.III.Ambulance.Full.Mod.v1.0.zip"
3. Copy the "Ambulance Full Warning" folder into the "modloader" folder, which is located in your game's root directory.
4. Done

**VC**:

1. Install the Ultimate Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.VC.Ambulance.Full.Mod.v1.0.zip"
3. Copy the "Ambulance Full Warning" folder into the "modloader" folder, which is located in your game's root directory.
5. Done
